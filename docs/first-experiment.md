# 첫 실행 실험 — 부모님 생활 센서등

## 목적
효도발견의 '문제 발견 → 공감 콘텐츠 → 제품 검토 → 성과 확인' 사이클을 1회 실행합니다.

## 소재
부모님이 밤에 일어나실 때 스위치가 멀어 불편한 순간.
과장된 사고/의학적 효과 주장은 피합니다.

## A안: 공감형 카드뉴스 (5장)
1. 표지: '엄마 집에 갔다가, 처음 알았던 불편'
2. '침대에서 불 스위치까지 몇 걸음'
3. '별거 아닌 듯해도 매일 반복되는 일'
4. '뭐가 제일 불편한지 먼저 물어봤다'
5. '부모님 집에서 발견한 작은 불편, 또 있나요?'

## B안: 생활 팁/제품 검토형 (15초)
0~3초: '밤마다 이 스위치가 멀었다면?'
3~7초: 침실 동선의 불편한 상황 소개
7~11초: 동작 감지 조명 설치 위치와 실제 밝기 확인(과장 금지)
11~15초: '우리 집에 맞는지는 설치 방식부터 확인하세요'

## 검수 및 측정
- 자연스러운 실사 이미지인지 검수
- 제품 가격·설치·안전 정보 및 제휴표기 확인
- 발행 후 24/72시간 실제 조회·공유·저장 수 기록
- 제품 링크 클릭과 수익은 실제 확인된 데이터만 입력
- A/B는 다른 형식이라 인과적 우열 판단이 아니라 탐색용 비교로 사용

## 후속
첫 발행 결과를 토대로 훅, 이미지 톤, 상품 소개 비중을 조정합니다.
