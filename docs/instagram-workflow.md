# 효도발견 인스타그램 에이전트 실행 규칙

자료 출처: 사용자가 제공한 「인스타그램 에이전트 스킬」 5쪽 PDF
원본 오픈소스: https://github.com/Jakeschincariol/instagram-agent-skill (MIT로 소개됨)
이 문서는 **효도발견에 맞춘 운영 절차**입니다. 원본 Claude 13개 스킬의 설치 또는 실행을 의미하지 않습니다.

## 13개 기능 → 운영 목적
- /ig-viral: 경쟁 계정의 공개 릴스 기준선 대비 성과 비교, 훅 구조 파악
- /ig-reel: 훅 3개 및 15~30초 대본/자막/컷 타이밍 작성
- /ig-profile: 프로필 12항목 진단
- /ig-plan: 주간 발행 계획
- /ig-caption: 첫 줄과 캡션 다듬기
- /ig-carousel: 1080×1350 카드뉴스 장별 문구
- /ig-story: 스토리 흐름 및 자발적인 DM 유도
- /ig-reply: 내 게시물 댓글 분류 및 답글 초안
- /ig-comment: 다른 게시물의 진정성 있는 댓글 초안
- /ig-dm: 협업 메시지 초안
- /ig-repurpose: 원본 1개로 여러 포맷 변환
- /ig-audit: 기존 게시물의 공유·저장·조회 반응 분석
- /ig-human: AI식 표현을 자연스러운 말투로 다듬기

## 최소 운영 루틴
월요일: 레퍼런스 5개 수집 → 1~2개 선정 → 주간 계획
화~금: 대본 또는 카드뉴스 → 사용자 승인 → 실제 게시 → 댓글 답변 초안
일요일: 게시물 지표와 제휴 성과 기록 → 다음 주 우선순위 조정

## 분석 입력 형식
원본 URL | 게시 계정 | 게시 일자 | 관찰 일자 | 조회수 | 계정 평소 조회수 중앙값 | 좋아요 | 댓글 | 공유 | 저장 | 주제 | 훅

중앙값이 없으면 '평균 대비 몇 배'를 계산하지 말고 '자료 부족'으로 표시합니다.
원본 확인이 어려우면 추정 수치로 채우지 않습니다.

## 기본 AI 요청 템플릿
'docs/voice.md를 기준으로 효도발견 인스타 운영안을 만들어줘.
대상: [부모님을 생각하는 성인 자녀].
참고 링크: [URL]. 원본과 다른 오리지널 각도를 선택해줘.
먼저 훅 3개와 선정 이유를 보여줘.
이후 카드뉴스 5~7장 또는 릴스 20초를 작성하고,
발행 전 내가 확인할 체크리스트를 붙여줘.
검증되지 않은 수치/후기/효능을 만들지 마.'

## 작업 안전
- 비공식 SNS 자동 로그인/스크래핑/자동 댓글·DM·팔로우 금지.
- 공식 기능 또는 허용된 API로만 게시 연동을 검토합니다.
- 링크와 지표는 출처·측정 일자와 함께 기록합니다.
- 초안은 사람이 검수한 뒤 발행합니다.
