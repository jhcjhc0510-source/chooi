# 효도발견 OS

콘텐츠 → 제품 → 수익 기록을 연결하는 단일 HTML 대시보드입니다.

## 실행

저장소의 `index.html`을 다운로드한 뒤 브라우저에서 열면 됩니다. 별도의 설치나 서버가 필요 없습니다.

## 주요 기능
- Instagram / Threads 콘텐츠 등록, 상태 관리, 제품 연결
- 제품 후보, 출처, 제휴 링크 및 검증 단계 관리
- 발행 콘텐츠별 클릭·주문금액·수수료 기록
- 운영 경고, 상위 수익 기여 콘텐츠, JSON 백업·복원, CSV 내보내기

## 주의
- 첫 버전은 localStorage 기반이며 데이터는 사용하는 브라우저에만 저장됩니다.
- SNS 자동 발행이나 쿠팡/인스타 자동 데이터 수집은 지원하지 않습니다.
- **저장소가 공개 상태입니다. 실제 고객정보·개인 토큰·비밀번호를 커밋하지 마세요.**
- 다른 기기에서는 저장 데이터가 동기화되지 않습니다. JSON으로 백업하세요.
