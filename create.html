① 무엇을 이야기할까요?

이 기능은 API 요금 없는 규칙 기반 초안 작성입니다. 사실·후기·효능을 임의 생성하지 않으며, 최종 문구는 직접 검수해야 합니다.

② 초안 확인·수정

스튜디오 저장 기능은 같은 브라우저에서 사용할 때 연결됩니다. GitHub에 데이터가 업로드되는 기능은 아닙니다.

③ 추천 작업 순서

1. 위에서 오늘 소재를 입력하고 초안 만들기 2. 어색한 문장 수정하고 이미지·영상 제작 3. '스튜디오에 초안 저장' → 검수 대기 → 승인 4. 발행 캘린더에서 날짜 설정 5. 실제 게시 후 스튜디오에 조회·저장·공유 기록
